# Assignment 2 - Nike Clone (Static Front Page and Product Page)

## Reference Site

- **Name:** Nike
- **URL:** https://www.nike.com
- **Screenshot:** _reference screenshot to be added_

## What I built

- `index.html` - homepage with header, navbar, cart icon and a grid of 8 product cards
- `product.html` - single product page with image, details, quantity selector and Add to Cart button
- `style.css` - plain CSS for colours, cards, buttons and footer
- Same footer on both pages
- `completion.pdf` - screenshots at phone, tablet and desktop widths

## Tools

- HTML and CSS only (no JavaScript)
- Bootstrap 5 (CDN) for the navbar and the responsive grid
